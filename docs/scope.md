# 产品范围 — 源码安全审计

## 目标用户

研发 / 安全团队，需要在**发版前**对自有仓库做白盒风险梳理，而不做线上渗透。

## In Scope

- 框架与语言栈识别  
- 路由 / API 入口、鉴权中间件线索  
- 危险 sink（SQL 拼接、命令执行、反序列化等）**代码位置**提示  
- 硬编码密钥 / 配置风险线索  
- 依赖与配置中的常见错误模式（提示级，非完整 SCA 替代）  
- Markdown / SARIF / 结构化 JSON 报告  

## Out of Scope

- 对运行中系统的 HTTP/浏览器探测  
- 登录、写操作、状态变更  
- 漏洞利用、PoC 攻击步骤  
- 未授权目标扫描  

## 与 surface-map 的边界

| | codeaudit | surface-map |
|--|-----------|-------------|
| 输入 | 源码路径 | 授权 URL |
| 网络 | 默认无业务流量 | 有限只读探测 |
| 输出 | 代码风险与修复建议 | 端点 / 技术栈地图 |
| 利用 | 无 | 无 |
